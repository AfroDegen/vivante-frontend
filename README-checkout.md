# Vivante Lagos Checkout

React 18 + TypeScript + Vite checkout with server-side order pricing
and ALATPay payment integration.

## Features

- Shopping cart
- Customer and delivery details
- Server-authoritative pricing
- Card and bank transfer payment selection
- Order persistence in Supabase
- Server-side payment verification
- Payment webhook endpoint
- Mock payment mode for development

## Installation

```bash
npm install
npm install @supabase/supabase-js
npm install -D vitest @types/node @vercel/node
